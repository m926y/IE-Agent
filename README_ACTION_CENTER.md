# 通知与待办中心

管理端顶部、司机端顶部的“通知”“待办”均可打开抽屉。通知支持全部/未读筛选、单条/全部已读、业务详情跳转、周报预览和Markdown下载。

待办来自实际未完成状态，按紧急、已逾期、今日、其他分组：风险案卷（重复报警沿用同案卷）、培训反馈审核/逾期培训、评分异议、设备数据核验、司机待回应提醒和待完成培训。关闭案卷、完成审核、结案或覆盖核验后自动更新。已读不等于完成。历史回放单独标注。

数据来自当前本地完整数据平台，所有入口由服务端重新读取有效账号与当前车队/司机绑定；计数与列表使用同一筛选。新接口 GET /api/center/data、POST /api/center/read 不采信客户端actor字段。司机无法查看其他司机、影子候选或未核实绑定的数据。

既有业务通知使用notification_events.read_at；周报完成、权重生效、导入结果从真实artifact/audit记录派生稳定事件ID，读取状态保存在action_center_reads，不需要复制业务事件或伪造完成通知。已读状态跨刷新/重启保留。权重生效通知不因仅预览、保存草稿而生成。其他人的周报不会展示。

抽屉打开每3秒更新，关闭时每15秒更新；当前页面成功的业务写入、回到窗口或标记已读会触发刷新。到期按北京时间，日期型截止按当天23:59:59计算。网络失败明确显示错误而非把数量写成0。

风险待办跳转包含案卷、回放及分页位置；培训与复核申请支持直接打开对应详情。司机端跳转相应功能页，业务提交继续走原有安全停车、课程审核和权限门禁。
