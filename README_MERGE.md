# 两版平台合并说明（2026-10-31）

当前可运行版本位于 `IE-Agent-merged-2026-10-31`，默认入口为 http://127.0.0.1:3100/ 。

合并基于本地完整平台 `IE-Agent-current-2026-10-27` 和同学提供的 `IE-Agent-main (1).zip`。原项目和解压副本均保留，合并没有覆盖原文件夹。3100服务现从本合并目录启动，业务数据库也是本目录下的独立副本。

## 冲突如何处理

1. **数据以完整平台为准。** 同学版的JSON对象数据库、少量演示事件和三门课程没有覆盖当前关系型SQLite业务库。已将新司机接口适配到500辆车、4000条历史评分和3152654条事件索引；保留现有账号、聊天、案卷、课程和学习记录。
2. **身份沿用当前系统。** 不导入对方不同的演示司机编号；服务端按登录账号读取当前绑定。历史记录按车辆参考，不能因为今天绑定了该车就认定过去也是本人驾驶。改绑后，旧账号的私人简报及反馈不会直接开放给新账号。
3. **角色沿用三种角色。** 管理员、安全员和司机分别授权。安全员拥有本车队简报和培训处置功能，仍不能调整模型权重、因子定义、严重度或参考口径；司机只能查看本人明细和匿名车队统计。
4. **培训保留完整闭环。** 对方自由文本提交方式不能替代答题及个人反思要求；培训仍仅向符合当前门禁的C/D级对象分配，课程必须已审核。课程新增分配快照，防止后续编辑课程改变已发任务的教学依据；旧任务首次保存时才留存，并明确显示留存阶段，不补造过去的分配版本。
5. **保存增加冲突保护。** 任务版本变化时拒绝旧页面覆盖；未保存学习记录离开前可选择保存、放弃或留在原页。保存选择题草稿不会提前判分，也不返回未作答题目的答案。
6. **模型保持千问。** 没有采用对方关闭外部AI的运行设置，仍使用当前服务端配置的 `qwen3.7-plus`。每日500份简报先依据完整数据生成确定的事实和规则分析，“让AI解读简报”再调用平台Agent读取该份报告，避免自动触发500次模型请求。AI交接单仍按原配置运行。
7. **两类日报分开。** 司机每日安全简报是个人历史安全参考；安全员交接单是当日未结风险、沟通与待办交接。两者分别留档，共用身份、权限、消息和模型接口。

## 主要新增代码

- `src/driver*.tsx`：司机五入口、行动摘要、分页证据、导航保护及学习入口。
- `src/daily-report.tsx`、`src/driver-integrated.css`：简报、趋势、安全动态、历史版本和反馈。
- `src/admin-driver-reports.tsx`：管理员和安全员查看简报、回复求助。
- `src/learning-report.tsx`、`src/training-recovery.tsx`：学习复盘及通知重试面板。
- `server/driver-integration.mjs`：将新功能连接到现有账号、完整数据、车队权限、简报队列和目标反馈。
- `server/learning-integration.mjs`：课程快照、培训/复核通知发件箱、按提交次数去重与重试。
- `server/daily-report/`、`server/driver-actions.mjs`：复用同学版的简报组织、校验和评分可比性逻辑，数据读取已改为完整平台适配器。
- `tests/driver-merge.test.mjs`：新增合并专项回归，使用临时数据库，不修改当前业务库。

`server.mjs`仍是统一鉴权、受控工具和公共接口入口；新模块通过本地私有数据库通道访问业务数据，浏览器和模型均没有任意SQL入口。Agent新增只读工具 `get_driver_daily_report`，继承当前身份及车队范围。

新增存储包括 `daily_safety_reports`、`driver_safety_goals`、`daily_report_jobs`、`driver_report_metadata`、培训和复核通知发件箱，以及 `training_tasks.course_snapshot/learning_progress` 字段。启动时幂等建立，不需要删除或重建数据库。后台队列每批处理5辆，生成结果、版本及通知在事务中留存；重启后继续未完成工作。

## 本地启动

需要Node.js 24或更新版本，使用原项目的数据库及历史索引目录结构。

```powershell
cd "C:\Users\12446\Desktop\大三上课程\IE亮剑\IE-Agent-merged-2026-10-31"
npm run start:local
```

修改前端后先运行 `npm run typecheck`、`npm run build`，再重启服务。默认3100；也可用 `LOCAL_PORT` 指定端口。不要同时在同一端口启动原项目。

本机 `node_modules` 和 `.runtime-tmp/python` 复用原项目依赖目录。迁移到其他电脑时应重新 `npm ci` 并按 `README_FULL_DATA.md` 配置Python重算依赖，不能把这两个目录链接当作独立安装包。只读历史索引仍在相邻的 `driving-safety-agent/var/history.sqlite`，本目录没有重复复制约784MB索引。

账号、课程、权重、消息等数据保存在 `var/platform.sqlite`；模型密钥在被Git忽略的 `.env.local` 中，仅服务端读取。日常启动不运行建库、清库或重新生成账号。后台自动生成需要本地服务持续运行，关闭页面不影响生成，关闭后台进程则暂停。报告日期会变化，但没有新数据时数据截止日仍显示2026-07-31，不能当作当天新增驾驶数据。

`.qw-pages/publish` 已更新构建产物及服务端模块，属于发布准备文件；本次交付是**本地完整数据版**，没有执行云端发布。云端PostgREST部署仍需另行配置相应存储迁移和后台队列，不能直接把SQLite私有通道当作云数据库接口。
