# 互动课程接入培训管理（2026-10-29）

> 更新：已增加8门阅读课与综合复盘（XA_T系列），原XA_M系列和成绩保留。培训新任务仅允许C/D且数据可信、身份核实的司机；详见README_EVALUATION_GOVERNANCE.md。下文8门4题描述指原题库。

已在本目录的Agent平台源码中接入8门课程、32道选择题，不依赖外部课程网站或iframe。

## 管理员路径

1. 培训管理 → 课程库与审核，选择课程并预览4道题、标准答案和解析。
2. 首次使用点击「加入课程库（待审核）」→「提交审核」→经人工核查后「确认审核通过」。不会自动批准既有课程。
3. 搜索并勾选接收司机（名单按200条分页全部加载），设置截止日期、强制性和学习目标。
4. 「确认分发」按司机逐人创建任务和站内通知；部分对象无法分配时逐项列明。重试同一批次不重复建单。
5. 需要安排另一轮培训时使用「新建下一批分发」，重新选择对象。
6. 培训台账 →「互动课程答题成绩」查看最近读取的200条任务成绩；点任务进入复核与逐题作答详情。既有台账列表仍支持分页。

## 司机路径

培训任务 → 进入课程答题 → 逐题提交 → 即时对错与解析 → 提交课程并查看总分。每课4题、每题25分；多选全部选对才得分。首次提交计分；退出或服务进程重启后从数据库恢复。全部完成后进入submitted，交管理员复核。重训由管理员另分配一轮，不能改写原任务成绩。

## 数据与权限

- 答案和判分逻辑保留在server.mjs的版本化题库（xing-an-quiz-v1-20261029），未作答题目不向司机返回标准答案或解析。
- 课程标识XA_M01至XA_M08。安装只新增draft；同编号其他版本拒绝覆盖和分发。
- 复用training_courses、training_tasks、notification_events及audit_logs，不需要新表或SQL迁移。逐题作答、题库版本、总分和完成时间保存在任务learning_record中；旧文字记录培训仍保留原流程。
- 任务写入使用已有状态和学习记录进行条件更新，进程内互斥配合数据库条件保护，防止重复作答改分。
- 新批次任务及通知采用幂等标识；通知失败时报告“任务已创建、通知待完成”，可重试修复。批量分发按对象返回部分成功，不声称整个批次具有跨对象事务。
- 管理员只能分配授权范围内对象；只给启用且绑定核实的司机分配。司机只可访问本人任务。管理员复核再次检查角色能力和车队范围。
- 原算法评分、事故概率、历史快照及司机绑定未改写。本次未向真实司机发送培训任务。
- 已编译网页和发布目录；未调用线上Agent平台的发布接口，也没有修改独立课程Demo网站。
