# 评分治理与评价分层处置（2026-10-29）

## 入口与组织方式

- 系统管理 → 规则与运营配置（`#/sm-config`）：初赛因子说明、权重设计、影响预览、版本比较及恢复。
- 安全评价 → 评价与分层处置（`#/ev-actions`）：授权车辆分层、已采取措施、提醒、当前司机交流及分层培训。原评分表、周度分析、根因与司机端继续保留。
- 培训管理 → 课程库与审核：阅读与分层课程、原有互动题库两个分组。

将“算法口径治理”和“评价后的业务处置”分成两处，避免在评分结果表中混入未经确认的操作。工作台会区分平台预警、评价提醒、已发送沟通、培训任务及未发布计划，不把建议和草稿算作已执行。

## 初赛依据与权重历史

因子说明直接由本项目初赛 `scripts/scoring_source/scoring/event_taxonomy.py`、`scoring_rules.py` 提取24种事件映射、严重度和暴露单位，权重使用最终冻结 `scoring_frozen.json`，并参考最终提交方法报告与初赛成果知识库。

保持14天观察窗口、14天半衰期、暴露调整、固定参考分布、零事件背景扣除及IMU专用上限的原口径。严重度不是逐次直接扣分。只调整六维权重，事故预测、可信度、原始事件与因子严重度不随之修改。A/B/C/D仍是按排名20%/40%/30%/10%的相对等级，不能用D级总数下降来评价调权效果。

设计名称、依据、权重、作者、时间、基础版本均留档；可以保存不生效的设计草稿，再载入预览。影响预览包括平均分、分值与等级变化、进出C/D人数、六维平均扣分、等级迁移矩阵及变化示例。两份历史版本可比较六维权重与全部车辆分值/等级。

“预览恢复此版本”读取对应归档；确认提交后**生成新版本**并复制历史评分、历史趋势、扣分台账、复核队列与评价规则的归档数值，赋予新来源版本。旧版本和设计记录不删除、不覆盖，不将活动版本指针简单倒退。恢复与重算均有预览凭据、并发版本检查、幂等提交和SQLite事务回滚。现行40天预测保持不变。

## 分层处置与培训边界

1. **D级**：优先核对证据和当班安全条件；确认后沟通、安排强化培训与人工复核。默认4门相关阅读课＋6道跨模块综合题，总计30题，分次完成。可调整为2—4门阅读课，综合复盘作为补充。
2. **C级**：围绕主风险定向辅导。默认3门阅读课18题，可按个体调整为1—3门；安排个人行动计划和管理员复核。
3. **数据质量不足**：优先核验设备、覆盖和身份，不安排行为培训。
4. **A/B级**：保留风险提醒、实时告警和常规跟踪，不创建培训任务。新出现严重实时风险仍可立即处置。

培训分发门禁覆盖原单人分配、互动课程批量分配、Agent培训工具及新分层计划。必须具备当前C/D等级、非低可信度、有效核实绑定和已审核课程；综合扩展课程只用于D级。分层计划先保存预览，再明确确认；课程或评分版本变化、账号绑定变化、计划超30分钟均要求重新准备。任务和通知同事务提交，重复确认不会重复建单。

现有同课程未结束任务会复用并明确列出，不机械叠加。C计划为辅导任务，D计划为强化必修；这是本项目教学安排，不是已验证的最优干预剂量，也不等同处罚。

任务保留分配时等级、评分版本和分层计划ID。调权或恢复导致司机跨档后，旧任务与成绩不自动改写/取消；新任务按新口径校验，待确认旧计划失效。旧记录缺少这些字段时如实显示未留档。

新课程ID `XA_T01—XA_T08` 与 `XA_TX`，题库版本 `tiered-reading-v1-20261029`。每门阅读课6题；原 `XA_M01—XA_M08` 的4题版本和成绩保留。司机在课程内阅读、作答、查看解析；答案在作答前不返回司机。
