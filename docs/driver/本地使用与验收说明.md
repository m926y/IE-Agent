# 本地使用与验收说明

当前候选按“只使用IE亮剑资料”收敛。本文替代V2系列指导文档中关于新增专业题库、外部AI、远端数据库联调的待办要求；旧文档保留作历史记录，不作为当前数据来源。

## 启动和账号

本机使用Node.js 24验证。项目依赖已经安装，双击项目根目录“启动本地工作台.cmd”，或执行npm.cmd start。默认地址为http://127.0.0.1:3100。首次运行读取来源文件并创建SQLite，后续运行读取已有状态，不覆盖操作记录。

账号文件位于IE-Agent/.local/accounts.json。local_admin为本地联调管理员；local_driver和local_other分别绑定到来源drivers.csv中的不同演示司机。口令随机生成并只写本地文件，不在文档中硬编码。技术账号与会话用于访问控制，不构成新的真实司机或算法结果。

如需独立环境，可设置LOCAL_STATE_DIR为本工作区中的另一个目录；LOCAL_PORT可改本地端口。不要覆盖已有目录来重置；使用新目录保留旧数据。源文件发生变化时，程序会拒绝静默覆盖旧库，应先核对来源再建立独立新库。

## 来源与功能边界

| 项目 | 当前处理 |
| --- | --- |
| 风险、评分、历史、台账、回放 | 仅导入IE亮剑/outputs/agent_starter/import，保留逐文件哈希和行数 |
| 三门来源课程 | 保留正文和原待审核状态；人工明确批准后才可分配 |
| 专业测验和学习自检 | 来源无题库及答案，已从界面和服务移除；旧请求返回410 |
| 学习复盘汇总 | 只整理课程、本人记录、反馈和真实人工复核意见，不生成新专业结论 |
| 外部模型和数据服务 | 默认本地模式关闭入口并阻断API，不发生模型调用 |
| 实时风险和效果证明 | 不提供；页面明确历史回放，缺少新数据时等待复评 |
| 外部导入、新课程文本及知识内容写入 | 本地来源策略拒绝；原文件不被业务操作改写 |

CSV中的空值保持缺失语义，不自动变为零风险。课程版本0代表文件导入基线，后续审核版本为本地工作流元数据；来源哈希始终关联原文件。

## 课程和司机闭环

管理员在“培训管理—课程库与审核”查看原课程，提交审核并明确确认批准。此操作需要团队自行核对内容，程序不会代替专业审核。批准后在“创建培训”选择司机和课程，填写目标与截止时间；没有来源告警时可作为通用培训，不能伪造风险关联。

司机进入“培训任务”，阅读分配时留存的课程正文，填写复盘和反馈，保存后刷新可恢复。提交后由管理员在台账复核，可以退回补充或通过。司机点击“查看学习复盘汇总”会读取最新记录并刷新任务状态。

三个来源课程都是演示课程，没有专业审核证明。验收脚本只在隔离测试库里执行批准和分配流程，干净候选库仍保持零任务与三门待审核课程。

## 数据库与故障恢复

SQLite包含真实主键和幂等键唯一约束。任务创建或提交时，数据库触发器在同一事务中记录待发提醒和技术事务审计。后台每秒处理待发项，通知记录、处理审计及完成标记在同一事务中提交；重启后继续处理未完成项。

账号不可达或接收人变化时不擅自改投；保留待处理状态。已有任务阶段变化时跳过过期提醒。应用层人工审计仍保留，技术事务审计不冒充用户审核意见。本地SQLite实现不等同于此前托管PostgreSQL实现；没有对远端库运行SQL迁移或做公网部署。

## 验收与候选清单

npm.cmd test执行真实来源文件、SQLite唯一约束、事务回滚、重启恢复、权限和学习汇总测试，并验证独立构建制品。此前的虚构业务夹具已删除，历史测试数量不能与当前来源验收数量直接累计。

浏览器脚本为scripts/source-ui-battery.mjs，需要可导入的Playwright和本机Chromium类浏览器。可用PLAYWRIGHT_MODULE、BROWSER_EXECUTABLE、QA_OUTPUT_DIR指定已有工具和截图目录。脚本记录页面异常、HTTP失败和外部请求；不会连接真实外部服务。

scripts/build-local-manifest.mjs生成代码、构建文件和来源哈希清单，位于review/local-candidate-manifest.json。该清单是可复核记录，不是数字签名。根目录默认启动的是本地数据模式；.qw-pages中的旧托管制品仅保留构建兼容验证，不包含本地SQLite或账号，不作为此次公网交付。

## 后续是否还需要开发轮次

按当前纯本地材料范围，原第四至第六轮已调整并收尾，不再预留额外功能轮次。仍需要团队人工审核三门课程并体验确认，这是内容和使用验收，不能由程序伪造。将来若需要专业考试、外部AI或公网服务，应作为另行确认的数据与部署范围。
