# IE Agent 本地材料工作台

默认入口只使用同级“IE亮剑”文件夹中的业务数据，不读取远端数据库、不调用外部模型或数据服务。原始CSV只读，运行产生的账号、学习记录、提醒和审计保存在本项目`.local/`。

已验证本机Node.js 24。已有依赖时直接运行：

```powershell
npm.cmd run build
npm.cmd start
```

新环境先执行 `npm.cmd ci` 安装代码依赖，并将已有 `IE亮剑` 文件夹放到项目同级。来源材料不随本仓库上传，缺少材料时不会自动下载替代数据。

也可双击[启动本地工作台.cmd](启动本地工作台.cmd)。访问`http://127.0.0.1:3100`，本地账号与随机口令见启动后生成的`.local/accounts.json`，请勿提交此文件。

业务数据来源为`../IE亮剑/outputs/agent_starter/import/`中的15个CSV，逐文件SHA256、行数及来源清单保存在`.local/source-manifest.json`。首次导入有500名演示司机、4000条评分历史、6267条扣分台账、883条回放；三门课程保持原始待审核状态，不会自动批准或生成培训任务。

本地联调账号是运行时技术账号，司机绑定取自来源文件，不代表真实人员核验。管理员可以在课程库核对现有内容后明确批准，再分配培训；课程正文不能在本地候选中另造或替换。学习记录、反馈、审批等属于用户在本地发起的工作流，不是外部风险数据。

材料没有专业题库，因此已移除测验和学习自检，保留课程阅读、复盘、反馈、人工复核和事实汇总。数据为历史回放，不能宣称实时监控或培训有效性已得到证明。

每日安全简报由本地后台在上海时间 07:00 后自动生成，并向已核实绑定的司机提供站内通知和历史报告；来源限制、目标跟踪与验收见[每日安全简报说明](docs/daily-report.md)。

```powershell
npm.cmd run typecheck
npm.cmd test
```
