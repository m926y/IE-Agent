# 线下培训预约

入口：培训管理→线下培训预约（#/tr-offline）。月历可切换月份和日期，填写开始/结束时间、会议室1—3、主题、具体内容，勾选参与司机并确认预约。时间均按北京时间保存和展示。

沿用现有培训资格：参与者必须有唯一有效且核实的司机账号绑定，并为高/中可信C、D级；车队范围在后端按当前账号校验。管理端可查看自己权限内的安排；其他范围仅展示匿名会议室占用。司机只看到自己被邀请的预约，不返回其他参与人的名单。

同会议室时间重叠、同司机不同会议室时间重叠均禁止；前一场结束恰好等于下一场开始允许预约。开始时间必须在未来，单场不超过12小时。预约、参与关系、通知及审计同事务提交；重复提交同请求键不会再次通知。

预约后给全部参与账号写入站内通知，消息包含时间、地点、主题与内容。司机在通知中心以及培训任务的“我的线下培训”可查看未来安排，待办也列出待参加培训。此推送为平台站内通知，不代表外部短信或手机系统推送；不把“预约/已读”记作实际签到或完成培训。

取消保留历史记录，释放时段并向参与司机发取消通知。已结束安排不可取消。未新增真实会议、任务或司机账号作为测试数据。

API：GET /api/offline-training/data?month=2026-11；司机可用upcoming=1查询个人后续安排；POST /create、/cancel。服务端不采信客户端actor字段，所有写入仅安全管理员可执行。

验证：tests/offline-training.test.mjs（冲突、权限、通知回滚、幂等和取消），tests/full-data.test.mjs（真实HTTP鉴权/预约/取消，隔离数据库）。
