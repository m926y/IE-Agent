# Agent 周报与平台操作工具

启动：Node.js 24+，`npm run build` 后 `npm run start:local`，地址 `http://127.0.0.1:3100/`。沿用 `.env.local` 的 qwen3.7-plus 配置，密钥不进入前端或 Git。

## 使用

- 打开智能助手，说“生成最近有数据的一周车队周报，输出HTML和Markdown文件”。对话会出现文件卡片，可分别下载两种格式。
- 说“分析D级车辆的评分分布和主要扣分维度”。统计走授权范围内全量分页数据，不只取前200行。
- 说“查看已审核课程，为D级车辆准备培训任务，七天内完成”。Agent先查询课程，再返回对象、截止时间、强制属性及排除原因，点击聊天里的确认按钮才写入。
- 说“创建一门疲劳驾驶培训课程草稿”，并描述内容与完成要求。确认后只建立草稿，需要在课程中心审核后才能分配。
- 助手底部或“系统管理→账号与角色”可下载 `.xlsx` 模板。替换示例行后上传，支持 `.xlsx` 和UTF-8 CSV；三列为“用户名、显示名、角色”，最多200行、文件小于2MB。角色可用司机/队长/安全管理员或 `driver/team_leader/safety_admin`。不要提供密码列。
- 上传后出现完整清单，也可继续说“检查刚上传的账号批次”。确认后整批创建。密码由后端随机生成，首次登录强制更换；加密保存的一次性密码CSV仅当前操作人可在一小时内下载一次，密码不会发送给模型。新司机账号仍需绑定车辆。

## 周报口径

默认周期为最新实际评分日向前六天，共七天。当前样本最新日为2026-07-31，所以默认报告为2026-07-25—07-31，明确标注历史数据，不把它称作当前自然周。指定日期没有数据时返回无数据，不能补造。

报告包含期末平均分、同车七天均分变化、A/B/C/D及分数区间分布、周内每日趋势、完整D级及低可信度清单、最多20辆重点关注车辆、六维平均扣分贡献和简单培训建议。各日安全分本身仍使用近14天观察窗。数字由后端计算；千问仅撰写定性管理建议，模型不可用时明确采用规则建议。

周报HTML为无脚本独立文件；Markdown可直接阅读或编辑。报告保留生成时的评分版本。文件保存在业务库中，只允许生成者在相同车队权限范围内下载，不是公开文件链接。本轮实现按需生成，未设自动定时发送。

## 工具与接口

| Agent工具 | 行为 |
|---|---|
| `generate_weekly_report` | 统计+建议+HTML/Markdown报告附件 |
| `analyze_fleet_data` | 全车队、D级、C/D或低可信度群体的均分/分布/趋势/维度贡献 |
| `get_training_courses` | 课程与审核状态查询 |
| `prepare_training_batch` | 单车或群体的待确认培训任务 |
| `prepare_training_course` | 待确认课程内容草稿 |
| `prepare_account_import` | 用户上传表格对应的待确认账号批次 |

HTTP：`POST /api/agent/report`、`/analysis`、`/accounts/preview`、`/training/preview`、`/course/preview`；`GET /api/agent/plan?id=...`；`POST /api/agent/execute {plan_id,confirm:true}`；报告及一次性凭据分别通过 `/api/agent/artifact`、`/api/agent/credentials` 下载。

创建操作仅允许具有全部车队权限的安全管理员。司机不能查看车队报告或执行批量操作；受限安全员/队长只能分析已授权数据。操作计划绑定创建者及车队范围，30分钟过期；培训提交时重新校验评分版本、课程版本、当前绑定和重复任务。低可信度车辆先核验，不自动分配行为培训。没有已审核课程时不能分配，不会自动批准原有草稿。

`server/agent-store.mjs` 在私有loopback网关中提供SQLite事务服务。每个批次的账号或培训任务、站内通知、审计和完成状态在同一事务中提交；失败整批回滚，重试幂等。原有页面流程和评分算法保持不变。

`agent_plans` 保存待确认计划，`agent_artifacts` 保存周报和加密凭据；`var/.agent-credentials.key` 是凭据加密密钥，应随数据库安全备份，不应公开上传。新工具表不开放通用REST写入。云端纯PostgREST部署没有对应事务服务时明确提示未配置，本轮只接入当前本地完整数据平台。

在数据库副本中覆盖统计、日期缺口、权限及附件属主、Excel模板真实解析、批次预检、显式确认、过期/旧评分版本拒绝、幂等、初始密码加密与一次性下载、账号/任务/通知故障回滚。不会为演示而在正式库创建账号或培训。
