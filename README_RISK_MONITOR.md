# 历史数据驱动的实时风险 Demo

依据 `Agent设计方案/实时风险监控实现方案_v1.0_2026-10-29.md`，在本地完整数据平台接入。入口：`http://127.0.0.1:3100/#/rm-live`，菜单“风险监控 → 实时风险演示”。

## 演示步骤

1. 管理员选择历史日期与车辆，建立回放。推荐 **2026-07-08、车辆1**，当前绑定 `preview_driver`。支持已绑定车辆或全部授权车辆，未绑定车辆仅在管理端按车辆核查。
2. 点击“播放时钟”（1/10/60/300倍速），或“下一个风险事件”。后端每250毫秒推进，网页每2秒查询，切换页面不停止时钟。首次从当天第一条实际记录前1秒开始；重启服务自动暂停，不补播停机期间时间。
3. 管理员所有页面顶部出现风险消息栏，进入案卷查看事件时间、真实回放接收时间、原始事件编号、证据、1/5/15分钟片段统计及司机网页接收状态。可以切换回放记录，案卷每页100条，历史案卷和证据均保留。
4. 使用 `http://localhost:3100/` 登录司机，可以与 `127.0.0.1` 的管理员保持两个独立 Cookie 登录。司机所有页面有简短预警，“今日风险”查看本人事件。
5. 管理员复核（确认/误报/证据不足），记录处置。**暂停后显式勾选“模拟已安全停车”**，司机才可提交反馈。不能由单个速度0或暂停播放推断真实停车。
6. 管理员完成处置与反馈核查后关闭案卷。确认的风险需要处置及已绑定司机反馈；误报可记录核查措施后关闭。反馈和课程分数不会自动关闭风险。课程按钮将司机、案卷、对应课程带入现有培训表单，仍要求课程审核及管理员确认。

## 实际实现

- 九类映射：30000/30005、41001/41029/41002、41003/41004/41009/41023、30002/30003/30017、11402/11403/11405/11406、11401、60292/60294、41006/41021、11804/11803。
- 历史原始报警尚无设备可靠性及原生严重度，均以**平台模拟**呈现。单哈欠仅提示；路口云端升级关闭；摄像头异常单列灰色；事故记录到达产生红色应急核实待办，不记为提前预测。
- 消息ID幂等，默认同车同场景相邻信号间隔不超过60秒保守合并片段，避免同时的低头与分心重复计数。此为待抽检试点参数，不假装固定采样周期。普通页面提醒默认30秒合并，更严重事故记录到达不受合并抑制。证据始终保留。
- 分心5分钟内至少2个独立片段形成**影子橙色候选**，不生成额外司机提醒；偏移P95缺同路线/同通道/相近速度可比窗口，关闭自动升级，不伪造基线。
- 红色未响应待办按真实服务器经过时间升级提醒授权安全员/负责人账号；默认60秒是运营试点目标，与回放倍速无关。片段/提醒合并与响应时限可在创建回放前配置，随会话存档。
- 只有唯一启用且已核实的当前司机绑定才生成司机消息；这是**当前演示绑定，不是历史当班身份认定**。绑定变更或停用后立即失去旧案卷访问权限。所有角色和车队范围在服务端重新校验。
- 事件处理、案卷、证据、站内通知与时钟游标同一个 SQLite 事务提交，失败整体回滚；重放不重复建单。复核、处置、司机反馈、关闭均留审计，复用 alerts / interventions / notification_events / training_tasks。
- 新增6张本地表：risk_replay_sessions、realtime_events、realtime_vehicle_state、risk_cases、alert_evidence、alert_deliveries。`history.sqlite` 只读，原评分、预测与历史快照不改写。

## 接口与文件

- `GET /api/risk/metadata`：管理员读取规则及授权车辆。
- `POST /api/risk/create`：管理员创建回放，date / vehicles / speed / config。
- `POST /api/risk/control`：仅创建者管理员控制 play / pause / next / speed / parking / stop。
- `GET /api/risk/live[?id=会话&offset=0]`：服务端按角色及车队过滤，包含时钟、案卷、统计及证据；司机读取时记录“网页客户端已获取”回执。
- `POST /api/risk/handle`：管理员复核、响应、处置和关闭。
- `POST /api/risk/feedback`：仅本人、显式演示停车后反馈。
- `server/risk-monitor.mjs` 为本地风险引擎，`server/local-database.mjs` 托管私有RPC与后台时钟，`server.mjs` 复用平台会话鉴权，`src/risk-monitor.tsx` 为两端页面及共用消息栏。

## 边界及后续接入

当前完成的是**历史回放驱动的平台预警 Demo**。没有车载厂商接口、车端鉴权、真实心跳/停车会话、视频或播报SDK，未对外开放实时遥测接入口，也不会下发真实终端或播放语音。网页获取不代表终端接收或司机听到；无报警/断线不代表安全。

正式接设备需新增设备鉴权与限流、事件字典及严重度验证、消息签名、接收延迟/乱序水位线、厂商下发与真实接收/播报回执。当前历史设备时间与服务器回放接收时间明确分列，历史延迟不当作线上网络时延。组合规则维持影子模式。纯托管 PostgREST 环境未部署此本地服务时明确返回503，不能仅发布静态页面宣称已上线。
